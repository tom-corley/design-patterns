# Design Patterns

Demonstrations of key design patterns in Java. Examples for all 23 of the GoF Design Patterns.



List of patterns:

```
creational
  - factory
  - abstractfactory
  - builder
  - prototype
  - singleton

structural
  - adapter
  - bridge
  - composite
  - decorator
  - facade
  - flyweight
  - proxy

behavioural
  - chainofresponsibility
  - command
  - interpreter
  - iterator
  - mediator
  - memento
  - observer
  - state
  - strategy
  - templatemethod
  - visitor
```
